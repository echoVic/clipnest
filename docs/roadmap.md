### 1. 开机自启
- 偏好设置加开关「登录时打开 Clipnest」。
- MyGo 已提供 `App.SetOpenAtLogin` 和 `App.OpenAtLogin`：macOS 13+ 加为登录项，Windows 写当前用户的 Run 项。
- 开关显示系统里的实际状态，因为用户可能在系统设置或任务管理器里关掉了。
- 开机自启时不弹出面板。
- macOS 上 MyGo v0.9.0 的 `WasOpenedAtLogin` 认不出登录启动：它在启动事件送达之前就去读了。Clipnest 暂时自己读启动事件（`native_darwin.go` 的 `launchedAtLogin`），MyGo 的修复见 [#2033](https://github.com/egoist/mygo/pull/2033)，发版后升级依赖并去掉。

### 2. 按条数保留历史
- 「历史保留策略」在容量（MiB）和天数之外，加「最多保留条数」，0 表示不限。
- 三个条件同时生效，从最旧的开始清理，常用语始终保留。和现有策略一样，只支持 SQLite。

### 3. Win+V 打开 Clipnest
- 现状：Win+V 被资源管理器占着，设成唤起快捷键会提示「被占用」。
- 先验证：在注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced` 的 `DisabledHotkeys` 里加上 `V`，重启资源管理器后，Clipnest 能否注册到 Win+V。在 Win10 和 Win11 上都要试。
- 做法：偏好设置加开关，打开时写注册表、重启资源管理器、注册 Win+V；关闭和卸载时还原。写注册表时保留 `DisabledHotkeys` 里原有的其他字母。
- 开关旁说明代价：系统 Win+V 面板里的表情、GIF、云剪贴板入口会失效，表情还能用 Win+. 打开。
- 不用全局键盘钩子：侵入性大，还容易被安全软件当成键盘记录器。

### 4. Windows 透明图片
- 读：剪贴板上只有位图、没有 PNG 时，现在读的是 CF_DIB，透明会丢。改为优先读 CF_DIBV5。
- 写：现在附带的 DIB 不带有效的透明信息，只认位图的程序里透明处可能变黑或变白。改为写带透明的 CF_DIBV5。
- 代码在 MyGo（`internal/windows/system.go` 的 `ReadImage`，`surface_drag.go` 的 `imageToDIB`）。优先给上游提 PR，不行再在 Clipnest 的 Windows 代码里绕过。
- 先在 Windows 上用几款常见软件实测缺口，修完再测一遍。

### 5. 远程窗口粘贴
- 先等用户回复：哪款远程软件、粘贴方向、具体现象。
- 最可能要做的：目标是远程控制类应用时，写完剪贴板后多等一会儿再发 ⌘V 或 Ctrl+V，让远程软件先同步过去。延迟可以按应用配置，或者内置一份常见远程软件的名单。
- 另外写进 README：远程会话全屏时，唤起快捷键可能被远程软件拿走；不想记录远程软件带来的内容，可以把它加进排除应用。

### 6. 选择数据目录
- 现状：只能通过启动参数 `--data-dir` 指定。
- 做法：偏好设置里选择文件夹，把数据复制过去，校验后切换并重启。新路径记在默认位置的一个小文件里，因为不能记在数据目录自己里面。
- 要处理：目标文件夹已有数据怎么办、复制中途失败的回滚、写入锁。

### 7. 导入导出
- 导出：历史、常用语和设置打成一个文件。
- 导入：合并进现有数据，按内容去重。
- 注意：打码只影响显示，数据库里是原文，导出文件里会有密码和密钥。导出前要提示，或者提供不导出敏感条目的选项。

### 8. Windows 截图文字识别
- 用系统自带的 Windows.Media.Ocr，和 macOS 一样在本机识别、不联网，偏好设置里的开关同样生效。
- 识别中文需要在 Windows 语言设置里装中文（含「光学字符识别」）；没装时偏好设置会说明，一种识别语言都没有时图片先排队。
- 实测结果和与 Vision 的差距见 [图片文字识别验证](image-text-validation.md#windows)。

## 暂缓

- **GIF 动图**：要先支持「记录复制的文件」：把文件拷进存储，粘贴时以文件形式放回，还要定大小上限和清理规则。工作量中偏大，等更多人要的时候和文件历史一起做。
- **远端没有剪贴板同步时的模拟打字粘贴**（虚拟机控制台、网页 KVM）：要处理输入法和特殊字符，等有人明确要再做。

## 不做

- **局域网或手机同步**：
  - 隐私模型会变。现在所有内容只在本机，同步后剪贴板内容要走网络。
  - 手机上做不到「自动」：iOS 和 Android 都不允许应用在后台读取剪贴板。
  - 已有替代：Apple 通用剪贴板、Windows 云剪贴板加微软 SwiftKey 输入法、LocalSend。
  - 以后如果要做，从「两台电脑之间、手动配对、端到端加密、默认关闭」开始，手机端不做。
