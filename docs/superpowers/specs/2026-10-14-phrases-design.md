# 常用语设计

- 日期：2026-10-14
- 状态：设计已逐段确认，待评审本文

## 背景

Clipnest 的历史面板（⌘⇧V）适合找回最近复制的内容，但不适合存放需要反复插入的固定文字，比如给 AI 工具的 prompt：

- 历史最多 200 条，新复制的内容会把旧的挤掉。
- 从面板粘贴一条，不会把它移到最前，常用的内容照样会沉下去。
- 「清空所有历史」会把它一起删掉。
- 1–9 的编号每次打开都会变，没法形成固定按键。

常用语是一块独立的功能：用户在面板里维护一组固定文字，按自己定的顺序排列，随时插入到原应用。

## 目标

- 在 ⌘⇧V 面板里切到「常用语」页，用和历史相同的方式（数字键、方向键、Enter、点击）插入。
- 在面板里新建、编辑、删除常用语，调整顺序。
- 和历史完全独立：单独存储，不受历史的条数上限、暂停记录、清空历史影响；插入的常用语不会进入历史。

## 不做

- 单独的全局快捷键、菜单栏入口。
- 标题、文件夹、标签。
- 变量占位（剪贴板内容、日期、光标位置等）。
- 输入缩写自动展开。
- 图片等非文字内容。
- 插入后恢复原剪贴板。
- 独立的管理窗口。
- 导入导出、同步。

## 交互

### 打开与切换

- 仍用 ⌘⇧V 打开面板。每次打开都显示「历史」页，所以「⌘⇧V 再按 1」始终是粘贴最近复制的内容。
- 顶部加「历史 / 常用语」切换。可以点击，也可以在焦点不在输入框时按 ← / → 切换（← 到历史，→ 到常用语）。焦点在搜索框里时，← / → 照常移动光标。
- 切换页面时保留搜索词，在新页面里重新搜索，选中项回到第一条。类型筛选只属于历史页：在常用语页隐藏，切回历史页时保持原来的选择。
- 不加新的全局快捷键，菜单栏不加入口。

### 列表与插入

- 按 1–9 直接粘贴，用 ↑↓ 或滚轮选择，按 Enter 或点击条目粘贴，点「仅复制」只复制不粘贴。这些都和历史一致。
- 每行显示内容的开头：把连续空白压缩成一个空格，取前 140 个字符；界面最多显示两行，超出部分用省略号。
- 右侧预览显示完整内容，下方显示字符数和「编辑」「删除」按钮；类型标签显示「常用语」。
- 顺序由用户决定。新建的排在最后。选中一条后按 ⌥↑ / ⌥↓ 上移或下移一位，编号随之变化，立即保存。有搜索词时不能调整顺序。
- 按 ⌘K 搜索。只搜内容，不区分大小写。
- 插入后剪贴板里留着这条常用语，不恢复原内容；这次写入不会被记进历史。

### 编辑

- 常用语页里，类型筛选那一行换成「新建」按钮（标注 ⌘N）。按 ⌘N 或点击按钮，打开编辑框。
- 编辑框的标题是「新建常用语」或「编辑常用语」，里面只有一个多行输入框，打开时焦点在输入框里。Enter 换行，⌘↩ 或「保存」按钮保存。内容全是空白时，「保存」按钮不可用。
- 选中一条后按 ⌘E，或点击预览下方的「编辑」，打开编辑框编辑这一条。
- 保存成功：关闭编辑框，刷新列表，选中刚保存的那条并滚动到可见位置。如果当前搜索结果里没有这条，先清空搜索词再选中它。
- 保存失败（校验不通过或写盘失败）：编辑框保持打开，内容不变，错误信息显示在编辑框里。面板的 toast 会被对话框挡住，所以不用 toast。
- 取消：按 Esc、点「取消」、点编辑框外面，效果相同。内容没改过就直接关闭；改过的话先弹出「放弃修改？」确认。选「放弃」才关闭并丢掉草稿，选「继续编辑」回到编辑框。
- 草稿：编辑框打开时面板被收起（失去焦点，或再按一次 ⌘⇧V），草稿保留在内存里。下次切到常用语页时，编辑框带着草稿自动打开。退出应用后草稿丢失。
- 删除：点击预览下方的「删除」，弹出确认「删除这条常用语？」。确认后删除，选中项移到下一条；删的是最后一条时，移到上一条。

### 空状态与异常显示

- 还没有常用语：显示「把常用的文字存起来，随时插入」和「新建常用语」按钮。
- 搜索没有结果：显示「没有找到这条常用语」和「试试更短的关键词。」
- 文件读不了：列表区域显示错误信息和文件位置，「新建」按钮不可用。

### 页脚提示

- 历史页：在现有提示后加「← → 常用语」。
- 常用语页：「↑↓ 切换」「1–9 粘贴」「⌥↑↓ 排序」「← → 历史」。

### 偏好设置

- 「清空所有历史」按钮下面注明「不会删除常用语」。

### 按键一览

对话框打开时、输入法组字时，面板不处理下表的按键（编辑框自己的按键除外），这和现在一致。正在粘贴时，新增的按键和现有的方向键、数字键、Enter 一样不处理。⌘ 在 Linux / Windows 上对应 Ctrl，和现有的 ⌘K 一致。

| 按键 | 条件 | 动作 |
|---|---|---|
| ← / → | 不带修饰键，焦点不在输入框 | 切到历史 / 常用语 |
| ↑ / ↓ | 不带修饰键 | 选中上一条 / 下一条（现有行为） |
| ⌥↑ / ⌥↓ | 常用语页，没有搜索词，焦点不在输入框 | 选中的常用语上移 / 下移一位 |
| 1–9 | 不带修饰键，焦点不在输入框 | 粘贴对应编号（现有行为） |
| Enter | 焦点在搜索框、列表或页面上 | 粘贴选中项（现有行为） |
| Esc | — | 有搜索词时清空，否则关闭面板（现有行为） |
| ⌘K | — | 聚焦搜索框（现有行为） |
| ⌘N | 常用语页 | 新建 |
| ⌘E | 常用语页，有选中项 | 编辑选中项 |
| ⌘↩ | 编辑框里 | 保存 |
| Esc | 编辑框里 | 取消（改过内容时先确认） |

## 数据与存储

### 文件

- 路径：数据目录下的 `phrases.json`，和 `history.json` 放在同一个目录（macOS 上是 `~/Library/Application Support/Clipnest/`；指定了 `--data-dir` 时跟随它）。
- 文件权限 0600，目录 0700。普通 JSON，不加密。
- 格式：

```json
{"version":1,"phrases":[{"id":"9f86d081884c7d65","text":"use flux-sdd impl\nfor each impl，use sdt\nuse worktree for each impl"}]}
```

- 每条只有 `id` 和 `text`。`id` 是 8 字节随机数的十六进制，编辑后不变。数组顺序就是列表顺序。
- 只存纯文字。内容原样保存，不去掉首尾空白。

### 校验

- 内容不能全是空白：「内容不能为空」。
- 必须是合法的 UTF-8：「内容编码无效」。
- 单条不超过 64 KB（65536 字节，大约两万个汉字）：「单条常用语最多 64 KB」。
- 总数不超过 500 条，新建第 501 条时拒绝：「常用语最多 500 条」。
- 不查重。

### 写入

- 新建、编辑、删除、移动都立即写盘：先在副本上修改，写盘成功后才替换内存里的列表。写盘失败时内存不变，返回「常用语保存失败：<原因>」。
- 写法和历史相同：在同一目录建临时文件，chmod 0600，写入，fsync，再 rename 替换原文件。这段代码从 `History.Save` 抽成公用函数，两边共用。
- 移动到边界（第一条再上移、最后一条再下移）时不写盘，也不报错。

### 读取与损坏处理

- 启动时读取一次。文件不存在时视为空列表。
- 读取大小上限和历史相同（256 MB）。
- 以下情况视为文件损坏：无法读取或解析；`version` 不是 1；超过 500 条；任意一条的 `id` 为空或重复；任意一条内容不合格。
- 文件损坏时进入只读状态：列表、详情、保存、删除、移动、插入全部返回「常用语文件无法读取，已停止修改：<路径>。修好或移走这个文件后重启 Clipnest。」，并且从不写这个文件。历史功能不受影响，应用照常启动。

### 和历史的关系

- 两个文件、两套代码路径，互不读写。清空历史、暂停记录、历史的 200 条和 32 MB 上限都不涉及常用语。
- 插入常用语时，写剪贴板后记下这次的剪贴板变化编号和内容 ID（和从历史粘贴时一样），剪贴板监听会跳过这次变化，所以不会进入历史。

## 代码结构

### 后端（Go）

**`phrases.go`（新文件）**

```go
type Phrase struct {
	ID      string `json:"id"`
	Text    string `json:"text,omitempty"`    // 列表摘要里省略
	Excerpt string `json:"excerpt,omitempty"` // 只在列表摘要里有
}

type Phrases struct { /* mu, path, items, broken */ }

func openPhrases(path string) *Phrases                  // 从不失败；读不了时进入只读状态
func (p *Phrases) List(q string) ([]Phrase, error)      // 按顺序返回摘要；q 为空时返回全部
func (p *Phrases) Get(id string) (Phrase, error)
func (p *Phrases) Save(id, text string) (Phrase, error) // id 为空时新建，追加到末尾
func (p *Phrases) Delete(id string) error
func (p *Phrases) Move(id string, delta int) error      // delta 只能是 -1 或 1
```

`Phrases` 自带锁，可以在任意 goroutine 里调用。

**`history.go`**：`History.Save` 里写文件的部分抽成 `writePrivateJSON(path string, v any) error`，行为不变。

**`desktop.go`**

- `Desktop` 增加字段 `p *Phrases`。
- `Choose` 里从「检查是否正在粘贴」开始的流程抽成 `deliver(e Entry, copyOnly bool) (PasteResult, error)`：检查是否正在粘贴和辅助功能权限，写剪贴板，记下 `lastRevision` 和 `lastID`，收起面板并激活原应用，等按键松开后发 ⌘V，最后处理结果和提示。`Choose` 只负责在主线程按 session 找到条目，再调用 `deliver`。历史的行为不变。
- 新增给前端调用的方法：

| 方法 | 说明 |
|---|---|
| `Phrases(q string) ([]Phrase, error)` | 列表摘要，支持搜索 |
| `PhraseDetail(id string) (Phrase, error)` | 完整内容 |
| `SavePhrase(id, text string) (Phrase, error)` | id 为空时新建，否则编辑；返回保存后的常用语 |
| `DeletePhrase(id string) error` | 删除 |
| `MovePhrase(id string, delta int) error` | 上移（-1）或下移（1） |
| `InsertPhrase(id string, copyOnly bool) (PasteResult, error)` | 取出内容，用 `newEntry` 转成 `Entry`（得到和剪贴板监听一致的 ID），再走 `deliver` |

**`main.go`**：打开 `phrases.json` 并传给 `Desktop`。不注册新快捷键，菜单不变。

**`bindings.ts`**：用 `go tool mygo generate` 重新生成。

### 前端（web/）

- **`index.html`**
  - 顶部的「历史 / 常用语」切换：两个按钮，用 `aria-pressed` 表示当前页，和类型筛选的做法一致。
  - 常用语页的「新建」按钮。
  - 编辑框 `dialog`：多行输入框、错误信息、「取消」和「保存」按钮。
  - 「放弃修改？」和「删除这条常用语？」两个确认对话框。
  - 偏好设置里「不会删除常用语」的说明。
- **`keys.js`（新文件）**：导出一个纯函数。输入是按键（key、修饰键、是否重复、是否在组字）和上下文（当前页、是否在输入、有没有搜索词、有没有选中项、是否正在粘贴、是否有对话框打开、是否是演示模式），输出要执行的动作。现有按键的规则原样搬进来，再加上本设计新增的按键。`app.js` 的 keydown 处理只负责执行动作。
- **`app.js`**
  - 新增状态 `view`（`history` / `phrases`）和 `draft`（正在编辑的 id 和内容）。
  - `refresh`、`render`、`updatePreview`、`choose` 按 `view` 调用对应的后端方法，渲染对应的行和预览；滚轮选择共用。
  - 刷新后可以按 id 恢复选中项（保存、移动后使用）。
  - 面板重新打开时回到历史页，关闭所有对话框，但不清空 `draft`。
  - 编辑框：拦截 `cancel` 事件和点击编辑框外面的操作，走取消流程；⌘↩ 保存。
- **`demo.js`**：内存里的常用语示例（包括本次讨论里的两条），以及上面 6 个方法的实现。校验规则和提示文字与 Go 一致。
- **`style.css`**：切换按钮、两行摘要、编辑框（比现有对话框宽，输入框的高度适合多行文字）的样式，以及深色模式。
- **README**：在「使用」「界面与交互」「历史与隐私」里补上常用语；验证命令改为 `node --test web/*.test.mjs`。

### 插入流程

1. 用户在常用语页选中一条（数字键、Enter 或点击）。
2. 前端调用 `InsertPhrase(id, false)`。
3. Go 取出内容，转成 `Entry`，进入 `deliver`：写剪贴板，记下 `lastRevision` 和 `lastID`，收起面板，激活原应用，等按键松开后发送 ⌘V。
4. 剪贴板监听读到的变化编号等于 `lastRevision`，于是跳过，内容不会进入历史。

## 出错处理

| 情况 | 处理 |
|---|---|
| 内容全是空白、编码无效、超过 64 KB、已满 500 条 | 不保存。编辑框保持打开，内容不丢，在编辑框里显示原因 |
| 写盘失败 | 修改不生效。保存时在编辑框里显示「常用语保存失败：<原因>」，删除和移动时用 toast 提示 |
| 文件损坏 | 只读。列表区域显示错误和文件位置，「新建」不可用；历史照常使用 |
| 没有辅助功能权限 | 和历史相同：弹出授权说明，可以选「这次仅复制」 |
| 自动粘贴失败 | 和历史相同：内容已在剪贴板里，提示手动按 ⌘V |
| 正在粘贴时又有操作 | 和历史相同：「正在粘贴，请稍后」 |
| 要操作的常用语已经不存在 | 提示「这条常用语已删除」，然后刷新列表 |
