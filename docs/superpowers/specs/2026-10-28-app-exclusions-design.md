# v0.1.7 按应用排除记录

用户已确认「设置 → 隐私」添加、移除应用，以 Bundle ID 保存规则，只排除新的记录，继续遵守暂停、系统授权与敏感标记。2026-10-28 的开发指令授权按此范围实现；不增加新一轮审批。

## 行为

- 默认排除列表为空，保持已有采集行为。
- 隐私页新增「排除应用」分组，原生应用选择器只选择 `.app`，显示名称和 Bundle ID，逐条移除。
- 读取文字或图片之前匹配规则，主动请求记录也不能绕过排除。
- 跳过的剪贴板版本记为已处理。同一版本在切换应用、移除规则或请求授权后不能重新入库；下一次复制重新判断。
- 设置变更不清空历史、不影响常用语、不重建已打开的历史会话；清空历史、保留策略和迁移不删除规则。
- 权限不足、暂停和私密标记仍优先；新增规则不会申请剪贴板或辅助功能权限。
- 排除为 macOS 功能。其他桌面系统保留已有复制行为，设置解释该能力不可用；浏览器演示用示例应用展示管理，不访问真实应用或剪贴板。

## 来源识别

现有 `nativeBridge.Target()` 读取 `NSWorkspace.frontmostApplication`，并不是操作系统提供的实际剪贴板写入者。扩展其元数据为 PID、名称和 Bundle ID。

每次首次检测到剪贴板版本变化，记录当时的应用元数据；即使系统尚未允许读取，也保留这一版本的来源。稍后从 Clipnest 设置主动请求读取，使用保留的来源，不能把它重新归为 Clipnest 或新前台应用。

获取元数据与读取内容前后继续核对版本和权限，避免把竞争中的内容入库。在 macOS 上已有排除规则而来源 Bundle ID 无法确认时，保守跳过并消耗该版本。

限制需在设置与 README 明确说明：后台应用复制、检测间隔内快速切换应用、第三方工具写剪贴板等场景无法保证识别真正来源。本功能提供基于检测时前台应用的过滤，不宣称安全隔离。

## 持久化

规则采用独立的小配置文件 `excluded-apps.json`，放在现有受写入锁保护的数据目录，使用 `writePrivateJSON` 的 0600、fsync 和原子替换语义。它是低频修改的应用配置，不保存历史正文或图片。相比给历史数据库和旧 JSON 同时增加新规则字段，此方案避免耦合历史迁移，兼容两种历史后端。

格式为版本 1 和应用数组，每个应用只有 `bundleID`、`name`。最多 128 项；Bundle ID 非空、最长 255 字节、只接受 ASCII 字母数字及 `. _ -`，名称非空、有效 UTF-8 且最长 256 字节。禁止空标识、重复标识和不支持的配置版本。按 Bundle ID 排序，重新选择同一标识只更新名称，不新增重复项。

保存成功才发布新规则。替换尚未发生的错误保留旧规则；替换已发生但目录同步失败时，内存与已发布文件一致并明确返回错误。配置损坏不能静默丢弃，应停止启动并保留原件，避免未经同意恢复记录。

## 代码边界

- `app_exclusions.go`：规则验证、读取、原子保存、不可变列表副本和匹配；由 `Storage` 持有，迁移不改变其生命周期。
- `native_darwin.go`：运行应用 Bundle ID 和所选应用的 NSBundle 元数据；不启动所选应用。
- `native_application_darwin.go`：原生 NSOpenPanel sheet，仅接受 `com.apple.application-bundle`；取消或退出时只完成一次选择。MyGo 0.7.1 的扩展名过滤把 `.app` 解析为 `com.apple.application-file`，真实应用包不符合该类型，因此此边界使用明确的 UTI，而不是扩展名推断。
- `desktop_exclusions.go`：原生选择器、添加/移除绑定、主线程操作保护、规则刷新和剪贴板版本处理。
- `desktop_clipboard.go`：每个版本的来源快照与读取前过滤。
- `preferences_exclusions.go`：沿用现有圆角分组的原生设置内容，避免继续扩充设置绘制文件。
- 浏览器演示及前端：添加/移除示例应用，保留原有历史会话、搜索、选择和保留策略草稿。

## 验收

1. 排除应用的文字、PNG、TIFF、主动读取均不读取正文、不入库。
2. 跳过后切换到允许应用或撤销规则，同一版本仍不会入库；新复制允许记录。
3. 等待系统授权期间保留来源；读取竞争和权限变化继续阻止入库。
4. 空列表不改变 v0.1.6 行为；有规则且来源未知时在 macOS 保守跳过。
5. 添加、去重改名、移除、重启、旧 JSON 后端迁移、历史清空均保持预期规则；坏文件和保存失败有明确错误。
6. 原生设置能添加、移除、取消；版本与检查更新入口保留，规则修改不改变历史或常用语。
7. 浏览器演示可操作并有清晰示例语义；深浅色和窄窗口可用。
8. Go 竞态测试、前端测试、Go/MyGo 静态检查及平台构建通过。

实现验证额外覆盖：非法 UTF-8 在 JSON 自动替换前拒绝；配置路径不是普通文件时停止启动；MyGo 退出后丢弃主线程派发时，添加和移除不得继续执行。

本轮开发更新应用版本为 0.1.7，并记录开发中状态。正式发布与签名安装包另按发布指令执行；发布时必须同步独立的 echovic-apps 官网，核验中英文内容、静态下载与自动部署。
