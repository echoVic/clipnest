# 隐私补强设计

日期：2026-11-17
分支：`feat/privacy-hardening`

## 目标

Clipnest 主打本地、隐私。现在只有两道防线：标记为机密的内容（`org.nspasteboard.ConcealedType` 等、Windows 的 `ExcludeClipboardContentFromMonitorProcessing`）不记录；macOS 上可以按应用排除。没打标记的密钥、令牌、卡号会原样进入历史、标题、摘要和搜索索引。

这次补三件事：

1. 识别密钥、令牌和银行卡号，默认遮罩后记录。
2. 按正则忽略内容。
3. 密码管理器清空剪贴板时，删掉刚记下的那条。

## 1. 识别密钥

### 识别范围

只收高置信的格式，宁可漏判也不误判：

| 类型 | 规则 | 遮罩后 |
|---|---|---|
| 私钥 | `-----BEGIN … PRIVATE KEY-----` 起，到对应的 END 行或文本结尾 | 保留 BEGIN/END 行，正文换成 `••••` |
| AWS 访问密钥 | `AKIA`/`ASIA` + 16 位大写字母数字 | 前缀 + `••••` + 末 4 位 |
| GitHub 令牌 | `ghp_`/`gho_`/`ghu_`/`ghs_`/`ghr_` + 至少 36 位字母数字；`github_pat_` + 至少 22 位 | 同上 |
| GitLab 令牌 | `glpat-` + 至少 20 位 | 同上 |
| Slack 令牌 | `xoxa-`/`xoxb-`/`xoxp-`/`xoxo-`/`xoxr-`/`xoxs-` + 至少 10 位 | 同上 |
| Anthropic 密钥 | `sk-ant-` + 至少 20 位 | 同上 |
| Stripe 密钥 | `sk_live_`/`sk_test_`/`rk_live_`/`rk_test_` + 至少 16 位 | 同上 |
| API 密钥 | `sk-`（可带 `proj-`）+ 至少 32 位，且含数字 | 同上 |
| Google API 密钥 | `AIza` + 35 位 | 同上 |
| JWT | `eyJ….eyJ….…` 三段，每段至少 8 位 | 同上 |
| 银行卡号 | 整条复制内容只有一个卡号：13–19 位数字，可用单个空格或连字符分组，常见卡组织前缀，通过 Luhn 校验 | `•••• ` + 末 4 位 |

令牌规则要求前面是词边界，`task-…` 这类标识符里的 `sk-` 不算。银行卡号只在整条内容就是卡号时识别，避免把文中的订单号、单号误判。一条内容里有多处时全部遮罩，类型取第一处。

### 遮罩后记录（默认）

- 只遮罩密钥那一段。复制一份 `.env`，其他行照常显示。
- 标题、摘要、搜索文本都由遮罩后的文字生成；原文只存在 `history_content.text`，用来粘贴。搜不到密钥本身，能搜到同一条里的其他文字。
- `history` 表新增 `secret` 列，存类型名，空字符串表示普通内容。数据库版本升到 5。读取详情时按 `secret` 重新遮罩，所以详情的标题、摘要也是遮罩后的。
- 同一段内容重新复制时，如果遮罩状态变了（比如之前关着识别），按新的状态更新标题、摘要和索引。
- 只对之后的复制生效，已有历史不回溯。

### 面板

- 列表项图标换成锁，读屏标签带上类型。
- 预览默认显示遮罩后的文字，类型标签显示密钥类型。预览区多一个「显示」按钮，点了才显示原文；换一条或关掉面板后恢复遮罩。
- 粘贴、仅复制都是原文。
- 不能存为常用语：⌘/ 菜单不列这一项，⌘S 提示原因。

### 其他选项

偏好设置里可以改成「不记录」（和机密标记一样直接跳过）或「不识别」（照常记录）。图片和图片里识别出的文字不在范围内。

## 2. 按正则忽略

- 隐私页「敏感内容」组里的「忽略内容」列表。每条是一个正则（Go RE2 语法，线性时间，不会卡死），匹配到的文字复制直接不记录。图片不受影响。
- 默认区分大小写、在全文任意位置匹配，可以用 `(?i)`、`^`、`$`。
- 添加时检查：不能为空、最长 512 字节、最多 64 条、不能重复、必须能编译、不能匹配空字符串（比如 `a*` 会把所有复制都忽略掉）。
- macOS 和 Windows 都可用。

## 3. 清空剪贴板时删除

- 默认开启，可关闭。
- 规则：Clipnest 刚记下一条复制后，下一次观察到的剪贴板变化是「清空」（没有任何格式，或只有空白文字），并且距离记下那条不超过 5 分钟，就删掉那条。
- 只针对捕获记下的那条。从面板粘贴或仅复制写入剪贴板后，记录的版本号已经变了，不会触发。
- 暂停记录时不检测。系统不提供剪贴板版本号时不检测。
- 两次轮询（300 ms）之间先复制别的再清空时，看到的只是清空，会删掉上一条。这种情况很少，接受。
- 恢复原内容的工具（比如 `pass`）无法识别。

## 设置存储

三项设置存在数据目录的 `privacy.json`，写法沿用 `excluded-apps.json`（私有权限、原子替换）：

```json
{"version":1,"secrets":"mask","clearSync":true,"ignore":[]}
```

文件不存在时用默认值。文件损坏或规则无效时启动失败并给出原因，和排除应用一样，不会悄悄丢掉用户的忽略规则。设置变化后跳过当前剪贴板内容，避免把已经在剪贴板里的内容按新规则补记下来。

## 偏好设置

隐私页新增「敏感内容」组，放在「排除应用」之后：

- 密钥、令牌与银行卡号：遮罩后记录 / 不记录 / 不识别
- 清空时删除：开关
- 忽略内容：输入框加「添加」按钮，下面列出规则，每条可移除

底部说明改为：「文字与图片仅保存在这台电脑。标记为机密的内容不会记录，识别到的密钥会遮罩。」

浏览器演示的偏好设置同步加上这一组，演示数据里加一条遮罩过的 AWS 示例密钥（`AKIAIOSFODNN7EXAMPLE`，AWS 文档里的示例值）。

## 测试

- 识别规则：表驱动的正反例，包括 Luhn、卡组织前缀、嵌在 `.env` 里的密钥、40 位 git 哈希和 kebab-case 标识符不误判。测试里的令牌在运行时拼出来，不在源码里出现完整的令牌字面量。
- 设置：默认值、校验（空、过长、重复、编译失败、匹配空字符串、超过 64 条）、读写往返、损坏文件。
- 捕获：遮罩、不记录、不识别、正则忽略、清空删除（5 分钟边界、中间有其他变化时不删、关闭时不删、粘贴写入后不删）。
- 存储：新库和升级后为版本 5；遮罩的标题和搜索；重新复制时更新遮罩状态；详情按 `secret` 遮罩。
- 前端：列表锁图标、预览「显示」、⌘S 和动作菜单拒绝存为常用语、演示数据。
