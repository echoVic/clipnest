# 存为常用语与键盘动作设计

- 日期：2026-11-16
- 状态：已逐段确认并实现

## 背景

竞品调研里最普遍的两个缺口：一是没法把历史里的一条留住，二是很多操作只能用鼠标。删除历史只能点预览区的垃圾桶，「仅复制」没有快捷键，打开链接要先复制再去浏览器粘贴。

常用语本来就单独存储，不受条数上限、清空历史和保留策略影响，顺序和编号也固定。所以这次不给历史加「固定」标记，只加「存为常用语」：不改数据库，也不引入第二个“留住”的概念。代价是图片存不了，因为常用语只支持文字。

## 按键

Windows 和 Linux 上 ⌘ 换成 Ctrl。弹窗打开、正在粘贴、输入法组字时不响应。带多余的 ⌥ 或 ⇧ 不触发，⌘/ 例外。

| 键 | 历史页 | 常用语页 | 何时生效 |
|---|---|---|---|
| ⌘↩ | 仅复制 | 仅复制 | 和 Enter 一样，搜索框里也生效 |
| ⌘S | 存为常用语 | — | 搜索框里也生效 |
| ⌘O | 打开链接 | — | 搜索框里也生效 |
| ⌘⌫ / Delete | 删除，立即生效 | 删除，先确认 | 只在焦点不在搜索框时；按住产生的重复按键忽略 |
| ⌘/ | 打开或关闭动作菜单 | 同左 | 搜索框里也生效。允许 ⇧，因为德语、法语键盘输入 / 要按 ⇧ |

⌘/ 参照 Slack、Google Docs 的快捷键列表和 Notion 的块操作菜单。⌘J 在 Edge 里是打开下载，WebView2 可能先拦截；⌘. 在 Windows 中文输入法里用来切换中英文标点。

如果焦点所在的控件已经处理了这个按键（调用了 `preventDefault`），面板不再处理。比如编辑框里按 ⌘↩ 保存时可能先关闭了编辑框，这条规则防止同一次按键又触发「仅复制」。

## 行为

**存为常用语**：打开常用语编辑框，标题为「存为常用语」，填好这条的完整内容，可以修改后保存，新的常用语排在最后。保存后停留在历史页，选中项不变，提示「已存为常用语」。已有未保存的草稿时，重新打开那份草稿，不覆盖。以下情况不打开编辑框，只给提示：
- 图片：提示「图片不能存为常用语」。
- 超过 64 KB 的文字：提示「超过 64 KB，不能存为常用语」。

**删除**：历史条目立即删除。删除后选中项留在原位置，也就是顶上来的下一条；删的是最后一条就选上一条，焦点回到列表。常用语沿用现有的确认框。

**打开链接**：只对链接条目生效，也就是整条内容是一个 http/https 地址。后端 `Desktop.OpenLink` 从面板快照读出这一条，用 `linkTarget` 再检查一遍协议，然后用系统默认浏览器打开。打开后收起面板，但不重新激活原应用，焦点留在浏览器。打开失败时提示错误，面板保持打开。浏览器演示里用 `window.open` 打开，并带 `noopener`。

**动作菜单**：预览区底部那一行加一个「⋯」按钮，菜单在它上方弹出，只列出当前条目能用的操作及快捷键：
- 历史页：粘贴、仅复制、存为常用语（图片没有）、打开链接（只有链接有）、复制图片文字（只在已识别时出现）、删除。
- 常用语页：粘贴、仅复制、编辑、上移、下移（有搜索词或已在边界时不显示）、删除…。

删除排在最后，用红色显示。键盘操作：↑↓ 移动，↩ 或空格执行，Esc 或再按 ⌘/ 关闭，焦点回到打开前的位置。每一项和对应快捷键调用同一个函数，即 `app.js` 里的 `perform`。

## 实现

- 不改数据库。后端只新增 `Desktop.OpenLink` 和 `linkTarget`。
- 纯逻辑放在带测试的模块里：
  - `web/keys.js`：按键规则。
  - `web/actions.js`：菜单内容和平台对应的快捷键文字。
  - `web/selection.js`：删除后选中哪一条（`indexAfterRemoval`）。
- `web/app.js` 只负责执行。

## 不做

- 固定历史条目、置顶。
- 右键菜单。
- 编辑历史后再粘贴。
- 给「复制图片文字」设快捷键。
- 在菜单里输入文字筛选。
