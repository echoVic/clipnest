# Clipnest

一个 Mac 优先的剪贴板历史面板。正常复制，随时找回；用数字、方向键、滚轮选择，确认后回到原应用粘贴。

## 使用

1. 将 `Clipnest.app` 拖入「应用程序」，双击打开。
2. 正常复制文字或图片，Clipnest 在菜单栏自动记录。
3. 在需要粘贴的输入框按 **⌘⇧V**，打开历史面板。
4. **1–9** 直接选择并粘贴；**↑↓ / 滚轮** 切换，**Enter** 确认；也可点击条目。
5. **Esc** 关闭（有搜索词时先清空）；点击面板外也会关闭。

**⌘K** 进入全文搜索。搜索框输入的数字保留为查询字符。右侧内容区的滚轮滚动长文本，左侧列表的滚轮切换条目。

**常用语**：点面板顶部的「常用语」，或在列表里按 **← / →** 切换。插入方式和历史相同（**1–9**、**↑↓**、**Enter**、点击）。**⌘N** 新建，**⌘E** 编辑，**⌥↑ / ⌥↓** 调整顺序，编号随顺序固定。每次打开面板都先显示历史。

第一次自动粘贴需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Clipnest。面板内提供跳转入口；系统列表没有 Clipnest 时，点击「+」并选择「应用程序」中的 Clipnest。尚未授权时可用「仅复制」。授权后重新唤起面板即可重新检查。

若 ⌘⇧V 被其他应用占用，将尝试 ⌥⇧V；两者都无法注册时可用菜单栏入口，面板会提示。用户从其他应用的输入位置唤起，才有自动粘贴的目标；首次打开无目标时保留为复制操作。

## 界面与交互

- 紫灰色的浅色界面，支持深色和跟随系统。
- 左侧列表提供内容类型、来源应用、相对时间、数字编号；右侧展示完整文本、代码、链接或图片。
- 鼠标经过不会改变键盘选择。触控板事件累积、限速，减少惯性造成的跳选。
- 每次打开固定当次历史及编号，新复制内容在下次打开显示。
- 常用语和复制历史分开：顺序由你决定，编号不受新复制影响。编辑时面板被收起，草稿会保留到下次打开常用语；退出应用后不保留。
- 粘贴时先归还焦点，检查目标应用仍在前台并等待选择键松开，再发送 ⌘V。
- 遵循系统减少动态效果设置，提供焦点样式、列表选中语义及键盘可达控件。

## 历史与隐私

- 支持纯文本、链接、代码、PNG 图片；普通富文本保存为纯文本，不保留原排版。文件列表不记录。
- 自动去重，重新复制的内容移到最前。默认保存最近 **200 条**，内容合计最多 **32 MB**。
- 单条文本上限 **512 KB**，图片 **8 MB**、最长边 **16000 像素**，超过限制跳过。
- macOS 每 300 ms 检查系统剪贴板变化编号，仅在变化后读取。非常快速、两次检查间被替换的内容可能无法记录。
- 本地保存并在重启后恢复，不上传、不联网分析。文字和图片以普通 JSON 保存（文件权限 0600），不是加密存储。
- macOS 忽略带 `ConcealedType`、`TransientType`、`AutoGeneratedType` 标记的剪贴板。未带这些标记的敏感文本无法可靠识别；需要时可暂停记录或清空历史。
- 数据位于 macOS 的 `~/Library/Application Support/Clipnest/history.json`。暂停状态也会保存。
- 常用语单独保存在同一目录的 `phrases.json`（普通 JSON，权限 0600），最多 **500 条**，单条最多 **64 KB**。清空历史、暂停记录不影响常用语；插入的常用语不会记入历史。文件无法读取时停止修改，不会覆盖原文件。

## 平台与发布状态

macOS 原生功能基于 MyGo、purego、AppKit / ApplicationServices，无 cgo，无 AppleScript 子进程。已支持菜单栏、全局快捷键、剪贴板采集、辅助功能检测、应用激活与粘贴按键。

当前 Release 提供 Intel / Apple Silicon 通用安装包（需要 macOS 12 或更高版本）。安装包已使用 Apple Developer ID 签名并通过 Apple 公证，下载后可以直接打开，不需要「仍要打开」等额外步骤；SHA-256 校验值见对应 Release 页面。

开发环境为 Linux。Mac 二进制已交叉编译、静态检查；原生 Mac 权限弹窗、跨应用焦点、多显示器与真实粘贴尚未在 Mac 实机验收。浏览器交互演示不等于系统粘贴验证。

Linux / Windows 能编译，桌面版仅提供历史与复制，不自动发送粘贴按键；主交付目标是 macOS。

## 本地开发

需要 Go 1.27.1（支持 Go 自动工具链）。HTML、CSS 和 JavaScript 均内嵌，运行时不需要 Node、Bun 或网络。`mygo.json` 描述应用包，图标位于 `resources/icon.png`。

开发入口为 `go run .`。浏览器演示入口为 `go run . --web 127.0.0.1:4183`，只允许绑定回环地址；演示使用内存示例数据，不读写真实剪贴板。

验证：`go test ./...`、`go vet ./...`、`node --test web/*.test.mjs`。Mac 包构建：`go tool mygo build -platform darwin/universal -skip-dmg .`，然后用 `scripts/package-macos.sh` 封装。

正式发布由 `scripts/sign-notarize-macos.sh` 在 macOS 上完成 Developer ID 签名、Apple 公证与 stapling；证书与公证凭据存放在本机钥匙串，不进入仓库。自行分发时请替换为自己的 Developer ID 与公证凭据。
