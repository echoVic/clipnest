# Clipnest

一个 Mac 优先的剪贴板历史面板。正常复制，随时找回；用数字、方向键、滚轮选择，确认后回到原应用粘贴。

当前正式版为 **0.1.7**，新增按应用排除记录。剪贴板记录权限、分组原生设置、SQLite 存储、历史保留策略、虚拟列表和搜索优化继续保留。正式版下载见 [GitHub Releases](https://github.com/echoVic/clipnest/releases)，改动记录见 [CHANGELOG](CHANGELOG.md)。

## 使用

1. 将 `Clipnest.app` 拖入「应用程序」，双击打开。
2. 正常复制文字或图片，Clipnest 在菜单栏自动记录。
3. 在需要粘贴的输入框按 **⌘⇧V**，打开历史面板。
4. **1–9** 直接选择并粘贴；**↑↓ / 滚轮** 切换，**Enter** 确认；也可点击条目。
5. **Esc** 先处理最上层弹窗或未保存的常用语，再清空搜索词，最后关闭面板；点击面板外也会关闭。

**⌘K** 进入全文搜索。搜索框输入的数字保留为查询字符。右侧内容区的滚轮滚动长文本，左侧列表的滚轮切换条目。

**常用语**：点面板顶部的「常用语」，或在列表里按 **← / →** 切换。插入方式和历史相同（**1–9**、**↑↓**、**Enter**、点击）。**⌘N** 新建，**⌘E** 编辑，**⌥↑ / ⌥↓** 调整顺序，编号随顺序固定。每次打开面板都先显示历史。

第一次自动粘贴需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Clipnest。面板内提供跳转入口；系统列表没有 Clipnest 时，点击「+」并选择「应用程序」中的 Clipnest。尚未授权时可用「仅复制」。授权后重新唤起面板即可重新检查。

若 ⌘⇧V 被其他应用占用，将尝试 ⌥⇧V；两者都无法注册时可用菜单栏入口，面板会提示。用户从其他应用的输入位置唤起，才有自动粘贴的目标；首次打开无目标时保留为复制操作。

## 界面与交互

- 紫灰色的浅色界面，支持深色和跟随系统。
- 偏好设置采用独立原生窗口、顶部图标页签和圆角分组：**通用**（外观、快捷键、更新与反馈）、**隐私**（暂停记录、剪贴板权限、排除应用、辅助功能）、**存储**（迁移、保留策略、清空历史）。面板设置按钮与菜单栏「偏好设置…」均可打开；切换页签保留未保存的保留策略，外观与历史面板同步。
- 权限说明使用同风格的 MyGo 原生模态窗口（macOS sheet），默认取消。自动粘贴未授权时可选择「这次仅复制」，弹窗不会改变已选历史。设置中保留版本号和检查更新入口；直接运行开发版时，版本号取自发布配置。
- 基于 MyGo 0.7.1 的原生 Spotlight 风格面板；macOS 唤起时不激活 Clipnest，支持覆盖全屏应用和不同桌面空间，并在鼠标所在屏幕内调整位置和大小。圆角和外部阴影由系统窗口绘制。
- 左侧列表提供内容类型、来源应用、相对时间、数字编号；右侧展示完整文本、代码、链接或图片。
- 历史每页读取 50 条摘要，列表仅渲染可见区域附近的条目；方向键和滚轮可继续选择后续内容，无需手动翻页。正文和图片在预览或粘贴时读取。
- 鼠标经过不会改变键盘选择。触控板事件累积、限速，减少惯性造成的跳选。
- 每次打开固定当次历史及编号，新复制内容在下次打开显示。
- 再次启动应用或从菜单选择「打开 Clipnest」会呈现当前面板，保留搜索与选择；全局快捷键和菜单栏图标点击用于切换显示。隐藏时结束当前读取会话，下次打开重新加载。
- 常用语和复制历史分开：顺序由你决定，编号不受新复制影响。编辑到一半时如果面板被收起（失去焦点，或再按一次 ⌘⇧V），草稿会保留到下次打开常用语；退出应用后不保留。
- 粘贴时先归还焦点，检查目标应用仍在前台并等待选择键松开，再发送 ⌘V。
- 遵循系统减少动态效果、减少透明度与增强对比度设置，提供焦点样式、列表选中语义及键盘可达控件；原生菜单和更新窗口使用中文。

## 搜索与预览

- 搜索正文、标题和来源应用，可按文字、链接、代码、图片筛选。支持中文短词和代码标点，按子串匹配、大小写不敏感，结果保持最新在前。
- SQLite 使用片段索引缩小搜索范围，翻页复用当前查询的结果。输入新关键词时取消旧查询，过期结果不会覆盖当前列表。
- 索引和结果缓存都有容量上限；超出索引预算的条目仍精确扫描，大量匹配不会被截断。索引随内容保存更新，增加一定后台写入和磁盘开销。
- 文字和常用语中的 Markdown 支持标题、列表、引用、强调、链接和代码块等轻量预览；复制和粘贴保留原文。预览引用远程图片时会请求对应图片地址。

在万条、每条约 2 KiB 的生成文本中，稀有双字词查询由约 **83 ms 降至 0.53 ms**。这是数据库查询基准，不包含输入防抖、界面渲染或首次索引构建；测试场景、写入成本和限制见 [存储与搜索验证记录](docs/storage-and-response.md#sqlite-搜索优化)。

## 历史与隐私

- 支持纯文本、链接、代码、PNG 图片；普通富文本保存为纯文本，不保留原排版。文件列表不记录。
- 自动去重，重新复制的内容移到最前。SQLite 历史**不限制条数**，按配置的容量和保留天数清理。
- 单条文本上限 **512 KiB**，图片 **8 MiB**、最长边 **16000 像素**，超过限制跳过。
- macOS 每 300 ms 检查系统剪贴板变化编号，仅在变化后读取。非常快速、两次检查间被替换的内容可能无法记录。
- 本地保存并在重启后恢复，不上传、不联网分析。新安装使用 SQLite（文件权限 0600），不是加密存储；文字和 Markdown 保存原文，图片保存为二进制。
- macOS 忽略带 `ConcealedType`、`TransientType`、`AutoGeneratedType` 标记的剪贴板。未带这些标记的敏感文本无法可靠识别；需要时可暂停记录或清空历史。
- 数据位于 macOS 的 `~/Library/Application Support/Clipnest/clipnest.sqlite3`，包含历史、暂停状态、保留策略和常用语。常用语最多 **500 条**，单条最多 **64 KiB**；清空历史、暂停记录和自动清理均不影响常用语，插入的常用语不会记入历史。
- JSON 兼容路径仍读取 v1 并校验完整单个文档；无效历史会停止启动并保留原件，常用语损坏时停止修改且拒绝迁移。SQLite 无法打开、设置无法读取或版本不受支持时停止启动；历史正文在读取详情时校验，损坏内容拒绝预览与粘贴。不会退回旧 JSON 或自动恢复备份，避免删除、清空的私密内容重新出现。
- 历史有变化时每两秒保存，打开面板前也会保存待写内容；异常退出可能丢失尚未保存的最近复制。常用语修改提交成功后才更新内存。
- 面板打开期间固定当次历史和内容，新复制和自动清理不会改变当前编号；手动删除、清空和保存清理策略会重新加载面板。删除和清理同步移除索引，清空历史同时清空索引。

### 剪贴板记录权限

macOS 15.4 起提供剪贴板访问策略 API；系统是否启用询问由 macOS 决定。Clipnest 在读取文字或图片前检查策略，格式枚举不读取正文：

- **允许**：自动记录；macOS 13–15.3 沿用原采集方式。
- **默认 / 每次询问**：后台不读取。先在其他应用复制普通文字，再在「偏好设置 → 隐私 → 剪贴板记录」点「开始记录」，确认权限说明后，由系统决定是否询问并允许这次读取。取消说明不会读取剪贴板。要持续自动记录，需在系统设置中把 Clipnest 的「从其他 App 粘贴」改为「允许」；一次读取成功不代表持续授权。
- **拒绝 / 无法确认**：停止读取新的复制，已有历史与常用语仍可使用。系统设置入口打开隐私与安全性页面，具体权限位置随 macOS 版本而异；默认状态的应用可能尚未出现在权限列表中。

记录权限与自动粘贴所需的辅助功能权限独立。打开面板、打开偏好设置或恢复记录不会主动请求记录授权；权限变化会在下一次轮询生效，不重排已经打开的列表。暂停记录及敏感标记过滤仍然优先。

### 按应用排除记录

在「偏好设置 → 隐私 → 排除应用」点「添加应用…」，选择一个 `.app`，即可跳过该应用的新复制。列表显示应用名称及 Bundle ID，点「移除」后从下一次复制重新判断。最多保存 128 个应用；重新选择同一 Bundle ID 只更新名称，不产生重复规则。

规则在读取正文或图片之前生效，主动请求记录也不会绕过。跳过的剪贴板版本不会在切换应用、撤销规则或稍后授权后补录；修改规则会消耗当前复制版本。已有历史与常用语继续可用，列表的搜索、选择和编号不受规则变更影响；添加规则不请求剪贴板或辅助功能权限。

来源按**首次检测到复制变化时的前台应用**判断，并非系统提供的实际剪贴板写入者。等待授权时保留当时来源，稍后从设置读取不会重新归为 Clipnest。后台应用复制、300 ms 检测间隔内快速切换应用或第三方工具写入可能无法识别真实来源。macOS 上排除列表非空但 Bundle ID 无法确认时保守跳过；这不是安全隔离机制。

规则独立保存在 `~/Library/Application Support/Clipnest/excluded-apps.json`（0600），仅包含应用名称和 Bundle ID。历史迁移、清空及自动清理不会删除规则；配置损坏时停止启动并保留原件，保存失败时提示错误。该功能仅适用于 macOS；浏览器演示使用明确标注的示例应用，不访问真实应用或剪贴板。

### 历史保留策略

在「偏好设置 → 存储 → 历史保留策略」调整：

- **历史内容容量**：默认 **512 MiB**，设为 **0** 表示不限制容量。
- **保留天数**：默认 **0**，表示不按天过期；设为正整数后清理超过该天数的历史。
- **保存并清理**：立即按新设置清理；之后在保存历史时和每小时自动执行。容量不足时从最旧的内容开始移除，常用语保留。

容量只统计历史正文和图片。搜索派生文本、索引、空闲页和 WAL 日志会额外占用磁盘，**数据库文件大小可能超过配置容量**。面板长时间不关闭时，读取快照可能延迟已删除内容和日志空间的回收。

## 旧用户升级

1. 升级后，原 `history.json` / `phrases.json` 继续可用；面板提示「一键迁移」，也可点击「稍后」。迁移前保持旧版 **200 条 / 32 MiB** 上限。
2. 点击「一键迁移」，或从「偏好设置 → 存储 → 本地存储」开始迁移。Clipnest 在本机临时数据库中校验历史原文、图片、顺序、时间和常用语等内容，再切换到 SQLite 并清理旧 JSON。
3. 切换前失败保留原数据，可重试；切换后旧文件清理失败时，SQLite 继续生效，界面提供清理重试。
4. 迁移后启用无限条数、历史保留策略和索引搜索。旧版应用不能读取新存储，请勿降级使用。

已有 SQLite 数据库首次打开新版时，会以事务升级并建立搜索索引；首次构建需要额外时间。数据格式、写入保护和迁移验证详见 [存储与响应改进记录](docs/storage-and-response.md)。

## 平台与发布状态

macOS 原生功能基于 MyGo、purego、AppKit / ApplicationServices，无 cgo，无 AppleScript 子进程。已支持菜单栏、全局快捷键、剪贴板采集、辅助功能检测、应用激活与粘贴按键。

Release 提供 Intel / Apple Silicon 通用安装包，使用 Apple Developer ID 签名并通过 Apple 公证；SHA-256 校验值见对应 Release 页面。**0.1.7 要求 macOS 13 或更高版本**，与 Go 工具链生成的二进制最低系统版本一致。

当前开发与验证在 macOS（Apple M2 Pro）进行。验证包含 Go 竞态测试、静态检查、61 项前端测试和 MyGo 原生设置、权限弹窗交互测试；应用排除另有 7 项真实原生验收，覆盖选择确认、取消、落盘、重启、去重、移除及退出，并通过错误 Bundle ID 对照验证断言。独立 WKWebView 程序验证了万条历史的分页、中文搜索、详情、过期请求拒绝和面板关闭重开。macOS Intel、Linux、Windows 另有交叉编译检查，未在这些目标系统运行测试。0.1.7 的规则、原生选择器及演示验证边界见 [应用排除验证记录](docs/app-exclusions-validation.md)。

浏览器演示和独立原生探针不等于完整的跨应用真实粘贴、多显示器和权限授权验收；这些流程仍需在各自环境验证。

Linux / Windows 桌面版提供历史、常用语与复制，不自动发送粘贴按键；主交付目标是 macOS。

## 本地开发

需要 Go 1.27.3（支持 Go 自动工具链），MyGo 固定为 0.7.1。HTML、CSS 和 JavaScript 均内嵌，运行时不需要 Node、Bun 或网络。`mygo.json` 描述应用包，图标位于 `resources/icon.png`。

本地开发可使用独立数据目录：`go run . --data-dir /tmp/clipnest-dev`。浏览器演示入口为 `go run . --web 127.0.0.1:4183`，只允许绑定回环地址；演示使用内存示例数据，不读写真实剪贴板。

浏览器演示地址加上 `?migration` 可体验旧用户的迁移提示、稍后和一键迁移流程；加上 `?large` 可体验万条历史的虚拟列表，仅改变示例状态。SQLite 驱动使用纯 Go 的 `modernc.org/sqlite`，保持无 cgo 构建。

浏览器演示可用 `?clipboard=default`、`?clipboard=ask` 或 `?clipboard=denied` 检查权限界面，加上 `&paste-permission` 可体验自动粘贴未授权的弹窗，不读取系统剪贴板。真实授权弹窗需要在打包后的 macOS 测试应用中验证：按 [Apple AppKit 官方说明](https://developer.apple.com/documentation/updates/appkit)，对测试应用的 bundle ID 设置 `EnablePasteboardPrivacyDeveloperPreview` 为 `true`，重启测试应用后验证默认、询问、允许和拒绝；测试后删除该开发者预览设置。浏览器演示与模拟测试不验证系统弹窗。

验证命令：

```sh
go test ./...
go test -race -count=1 ./...
go vet ./...
go tool mygo vet .
node --test web/*.test.mjs
```

搜索基准：`go test -run '^$' -bench '^BenchmarkSQLiteSearch' -benchtime=5x -count=1 .`。

Mac 本地预览包构建：`go tool mygo build -platform darwin/universal -skip-dmg -skip-notarize -sign - .`。如需压缩，可运行 `scripts/package-macos.sh <Clipnest.app> <输出.zip>`；该脚本使用临时签名，仅用于预览，不用于正式发布包。

正式发布由 `scripts/sign-notarize-macos.sh` 在 macOS 上完成 Developer ID 签名、Apple 公证与 stapling；证书与公证凭据存放在本机钥匙串，不进入仓库。自行分发时请替换为自己的 Developer ID 与公证凭据。

自动更新由 `mygo.json` 的 `updates` 配置（公钥和发布仓库）。签名更新包的私钥不在仓库和配置里，发布时通过环境变量传入：`MYGO_UPDATER_PRIVATE_KEY="$(cat <私钥文件>)" scripts/sign-notarize-macos.sh`。没有私钥时 `mygo build` 照常构建、只是不生成更新包，所以发布脚本缺少它时会直接停止。
